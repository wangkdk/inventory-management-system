== 개요

=== 에러 응답

에러는 RFC 9457 ProblemDetail 형식으로 응답한다. 클라이언트는 ``code``로 분기한다. ``title``은 코드마다 고정된 문구이고, ``detail``은 참고용이다.

==== 에러 코드

==== 다시 시도 (503)

같은 상품에 요청이 몰려 재고 잠금을 3초 안에 얻지 못하면 ``STOCK_LOCK_TIMEOUT``(503)으로 응답한다. 요청은 하나도 반영되지 않았으므로, 잠시 뒤 같은 요청을 다시 보내면 된다. 클라이언트의 요청 타임아웃은 3초보다 길게 잡아야 이 응답을 받을 수 있다.

include::{snippets}/error-stock-lock-timeout/http-response.adoc[]

=== 요청 키

입고와 출고는 ``Idempotency-Key`` 헤더로 요청 키를 받는다(선택, 64자 이하). 응답을 받지 못해 같은 요청을 다시 보낼 때 같은 키를 쓰면, 재고에는 한 번만 반영되고 처음 처리한 결과를 돌려받는다. 결과의 수량은 지금 수량이 아니라 처음 처리한 직후의 수량이다.

- 같은 키로 상품, 유형, 수량이 다른 요청을 보내면 ``IDEMPOTENCY_KEY_MISMATCH``(422)로 거절한다
- 처음 처리할 때 실패한 요청은 키를 남기지 않는다. 같은 키로 다시 보내면 다시 처리한다
