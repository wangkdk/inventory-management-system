# 재고 관리 시스템 용어 사전

| **한국어** | **영어** | **설명** |
|---|---|---|
| 상품 | Product | 입고, 출고, 재고 조회의 대상이 되는 상품 종류. 개별 물건 하나가 아니다 |
| SKU | SKU (Stock Keeping Unit) | 상품 종류 하나를 현장에서 식별하는 코드. 바코드 값에 해당한다. 상품마다 하나이며 중복되지 않는다. 등록 전에도 요청하는 쪽이 알고 있는 유일한 식별자다 |
| 재고 | ProductStock | 상품 종류 하나의 현재 수량. 상품과 1:1 |
| 재고 수량 | quantity | 지금 몇 개 있는지. 0 이상 |
| 입고 | Inbound | 재고 수량을 늘리는 일. 등록되지 않은 SKU면 상품을 먼저 등록한다 |
| 출고 | Outbound | 재고 수량을 줄이는 일. 재고보다 많이 뺄 수 없다 |
| 입출고 기록 | ProductStockMovement | 입고나 출고 한 번의 기록. 추가만 하고 고치지 않는다 |
| 변동 뒤 수량 | quantityAfter | 기록 시점에 처리를 마친 직후의 재고 수량. 통장의 "거래 후 잔액" |
| 등록 | Register | 새 SKU를 상품으로 만드는 일. 입고의 일부로만 일어난다 |
